======================
UBFABRIC Driver
======================

UBFABRIC is the kernel-space fabric infrastructure framework for the MAMI
(Management Architecture and Model Interface) subsystem. It provides a layered
architecture for user command dispatch, device management, resource discovery,
memory/register mapping, event handling, interrupt processing, and logging.
